# DevOps Atölyesi Lab Portalı

Bu portalda yalnız kayıtlı olduğunuz eğitimin konu başlıkları, labları, projeleri ve indirme paketleri gösterilir.

## Eğitiminiz

- [DevOps Practitioner eğitim içeriği ve paketi](courses/devops-practitioner-5-day.md)
- [Docker ve Kubernetes eğitim içeriği ve paketi](courses/docker-kubernetes-2-day.md)

Eğitim sayfanızdaki **Eğitim Paketini İndir** düğmesi bütün labları ve başlangıç dosyalarını tek ZIP içinde sunar. Bir labın yalnız kendi başlangıç dosyalarını almak isterseniz lab başlığının altındaki ZIP bağlantısını kullanabilirsiniz.

## Çalışma Akışı

1. Eğitim paketini indirin.
2. Labları paket içindeki sırayla uygulayın.
3. Sonucu rehberdeki gerçek Docker, Kubernetes, Git veya HTTP komutlarıyla doğrulayın.
4. Eğitim sayfasında size atanmış projeyi tamamlayın.

Lab paketleri çözüm dosyası veya kullanıcı bilgisi içermez.
